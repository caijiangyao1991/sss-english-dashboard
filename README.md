# 小糍粑 SSS 儿歌启蒙打卡工作台

一个面向家长和低龄儿童的 SSS 英语启蒙内容工作台，按百度网盘中的 DAY 目录组织内容，包含：

- 每日 SSS 儿歌为主线，按当天内容搭配口语和部分绘本
- 3 个月内容计划；当前已更新至 DAY 34
- 学习资源库
- 每日文字、心情和照片打卡
- 内容创作者上传和管理入口
- 成长数据和连续打卡展示
- 移动端自适应布局

## 本地运行

```bash
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080`。

## 数据说明

当前版本是无需后端即可演示的前端原型：打卡状态保存在 `localStorage`，上传的图片、视频等文件保存在浏览器 `IndexedDB`。同一浏览器可持续使用，但不同访客之间不会同步。

正式上线用于公开引流时，建议接入对象存储（阿里云 OSS / 腾讯云 COS）和云数据库，并增加手机号登录、微信分享、后台权限及线索收集功能。
